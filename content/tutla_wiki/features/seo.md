Most of the work is automatic. This page lists what you get for free and the few things that depend on you.

## Generated automatically

| Output | Where | Contents |
| --- | --- | --- |
| Page metadata | In each page's HTML head | Title, description, keywords, canonical URL, author, robots directives |
| Social tags | In each page's HTML head | Open Graph and Twitter card, with the first image on the page |
| Structured data | In each page's HTML | JSON-LD describing the page as an article, with dates and author |
| Sitemap | `/sitemap.xml` | Every page with last modified date, change frequency, priority and images |
| Robots | `/robots.txt` | Allows crawling of the site and points to the sitemap |
| LLM index | `/llms.txt` | A grouped, plain-text list of every page with its summary, for AI tools |
| Static HTML | Every page | Pages are rendered at build time, so crawlers see full content immediately |

New pages, including pages synced from GitHub, are added to the sitemap and to `llms.txt` without any extra step.

## Where each value comes from

| Output | Source |
| --- | --- |
| `<title>` | `title` frontmatter, followed by "Tutla Wiki" |
| Meta description | `summary` frontmatter |
| Keywords | `tags` frontmatter |
| Canonical URL | The page's path, so `index.md` files have no trailing `/index` |
| Social image | First image in the page body |
| Last modified in the sitemap | `updated`, otherwise `created` |
| Sitemap priority | Higher for shallower pages: the root first, then top-level project pages |

## Checklist for good SEO

1. A unique, descriptive `title`.
2. A `summary` of about one sentence, under 160 characters.
3. `updated` set to the date of the last real change.
4. Alt text on every image, and the most representative image first.
5. Headings that describe their sections.
6. Links to related wiki pages, which help crawlers discover content.
7. Lowercase, hyphenated file names that read well in a URL.

## Robots

`robots.txt` is generated by the site. Everything is crawlable except `/api/`. Several AI crawlers are named explicitly and allowed to read the pages and `llms.txt`. To change those rules, edit `src/app/robots.ts`.

## Avoiding duplicate content

- Do not copy the same text onto two pages. Link instead.
- If a page moves, leave a `redirect` at the old location.
- A page that exists only as a draft should be left out of `sidebar.json`, but remember it is still public and indexed.
